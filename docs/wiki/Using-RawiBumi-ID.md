# Menggunakan RawiBumi

Aplikasi memandu Anda melalui sebelas langkah di rel kiri. Alt+1–Alt+9 sesuai dengan langkah 1–9; Alt+0 membuka Hasil (langkah 10). Buka Laporan & ekspor (langkah 11) dari rel atau palet perintah. Panduan lengkap dalam bahasa Inggris dan Indonesia ada di `/manual/` dalam aplikasi.

| Langkah | Pintasan | Yang Anda lakukan |
|---|---|---|
| 1 Proyek & lokasi | <kbd>Alt</kbd>+<kbd>1</kbd> | Nama, koordinat, zona waktu, elevasi; alamat; jenis instalasi; gambar latar terkalibrasi (opsional). |
| 2 Komponen | <kbd>Alt</kbd>+<kbd>2</kbd> | Pilih modul dan inverter dari pustaka, atau impor berkas PAN dan OND. |
| 3 Geometri | <kbd>Alt</kbd>+<kbd>3</kbd> | Gambar atap (persegi, poligon, lubang), penghalang dengan tinggi dan zona larangan; atur bidang tiap atap. |
| 4 Tata letak PV | <kbd>Alt</kbd>+<kbd>4</kbd> | Isi atap dengan modul: orientasi, pemasangan, kemiringan, azimut, celah, meja, jarak tepi, jarak baris, perataan sembilan titik. |
| 5 Sistem | <kbd>Alt</kbd>+<kbd>5</kbd> | Konfirmasi bangunan, periksa jarak, lihat kelompok orientasi, atur inverter dan isi tabel string tiap MPPT (atau Sarankan). |
| 6 Kelistrikan | <kbd>Alt</kbd>+<kbd>6</kbd> | Gambar jalur string, tugaskan string ke MPPT, pisah, gabung, balik, pindah atau tukar modul; pemeriksaan langsung. |
| 7 Cuaca | <kbd>Alt</kbd>+<kbd>7</kbd> | Ambil atau impor data cuaca setahun; bandingkan ERA5 dengan data lokal di daerah tropis berawan. |
| 8 Rugi-rugi & jaringan | <kbd>Alt</kbd>+<kbd>8</kbd> | Atur rugi-rugi, optik dan termal, profil beban, tanpa ekspor dan akurasi bayangan. |
| 9 Simulasi | <kbd>Alt</kbd>+<kbd>9</kbd> | Pemeriksaan awal, lalu simulasi per jam setahun dengan bayangan dekat. |
| 10 Hasil | <kbd>Alt</kbd>+<kbd>0</kbd> | Energi, hasil spesifik, rasio kinerja, diagram rugi, tabel inverter dan MPPT, P50–P95. |
| 11 Laporan & ekspor | Rel / palet perintah | Laporan (HTML atau PDF), CSV 10 kolom, dan berkas proyek. |
