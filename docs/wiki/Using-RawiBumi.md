# Using RawiBumi

The app walks you through eleven steps on the left rail. Alt+1–Alt+9 match steps 1–9; Alt+0 opens Results (step 10). Open Report & export (step 11) from the rail or command palette. The full manual, in English and Indonesian, is at `/manual/` in the app.

| Step | Shortcut | What you do |
|---|---|---|
| 1 Project & site | <kbd>Alt</kbd>+<kbd>1</kbd> | Name, coordinates, time zone, elevation; address; installation type; an optional calibrated background image. |
| 2 Components | <kbd>Alt</kbd>+<kbd>2</kbd> | Choose modules and inverters from the library, or import PAN and OND files. |
| 3 Scene | <kbd>Alt</kbd>+<kbd>3</kbd> | Draw roofs (rectangle, polygon, holes), obstacles with heights and keep-out zones; set each roof's plane. |
| 4 PV layout | <kbd>Alt</kbd>+<kbd>4</kbd> | Fill a roof with modules: orientation, mounting, tilt, azimuth, gaps, tables, setbacks, row pitch, nine-point alignment. |
| 5 Systems | <kbd>Alt</kbd>+<kbd>5</kbd> | Confirm buildings, check distances, see orientation groups, size inverters and fill each MPPT's string table (or Suggest). |
| 6 Electrical | <kbd>Alt</kbd>+<kbd>6</kbd> | Draw string paths, assign strings to MPPTs, split, join, reverse, move or swap modules; live checks. |
| 7 Weather | <kbd>Alt</kbd>+<kbd>7</kbd> | Acquire or import a weather year; compare ERA5 with a local dataset in cloudy tropical regions. |
| 8 Losses & grid | <kbd>Alt</kbd>+<kbd>8</kbd> | Set losses, optics and thermal, load profile, zero export and shading accuracy. |
| 9 Simulate | <kbd>Alt</kbd>+<kbd>9</kbd> | Preflight checks, then the hourly yearly simulation with near shading. |
| 10 Results | <kbd>Alt</kbd>+<kbd>0</kbd> | Energy, specific yield, performance ratio, loss diagram, inverter and MPPT tables, P50–P95. |
| 11 Report & export | Rail / command palette | Report (HTML or PDF), the 10-column CSV, and the project file. |
